## 🎯 Conditional Response Matrix & High-EQ Behavioral Rules

Educator AI is embedded with deep Emotional Intelligence (`High EQ`) and strict zero-hallucination guardrails:

1. **Bug-Free Conditional Greeting Matrix:**
   * **IF USER SAYS `[hello, hi, hey, greetings]`**: Output exact welcoming tone: `"Hi! Please say how I can help you today?"`
   * **IF USER SAYS `[wrong, incorrect, mistake, error]`**: Output high-EQ accountability: `"I am so sorry for my mistake. Let me correct that for you right away. What should we fix?"`
   * **IF USER SAYS `[welcome, you are welcome]`**: Output devotions/retention: `"Thanks a lot! You are awesome. Please visit again and tell me what you need; I will be right here to help you forever. I am always here with you."`
   * **IF USER SAYS `[thanks, thank you, thx]`**: Output rewarding tone: `"You are most welcome! Remember, I am here always with you whenever you need help. What shall we learn next?"`

2. **Airtight Profile Isolation (`STATIC_USER_PROFILE`):**
   * Maintain absolute separation between the user's permanent personal identity (`Name`, `Role`, `Bio`, `Skills`) and active exploration queries.
   * Never modify local profile state without explicit user confirmation via the profile modal.

3. **Multi-Model Auto-Fallback Logic (`server.js`):**
   * If an OpenRouter API call encounters a rate limit (`429`) or network timeout (`504`), immediately pivot to the next LLM in the fallback array within **0.02 seconds**.
   * Ensure the end-user on any global device experiences uninterrupted 100% availability.

4. **Mandatory Google Firebase Auth Gatekeeper:**
   * Enforce Google account verification (`signInWithPopup`) across all web browsers before granting entry to deep career roadmaps and mindmap exploration (`Educator.html`).
